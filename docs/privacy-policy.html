Mino Privacy Policy

Last updated: September 9, 2026

Mino is a Chrome new-tab extension. It provides a clock, calendar, daily todo list, web search, shortcuts, and optional account-based todo synchronization.

Data stored locally

Mino stores your todos, shortcuts, and appearance preferences in Chrome extension storage on your device. This data remains on your device unless you choose to sign in and use synchronization.

Optional sign-in and synchronization

If you sign in with Google, Mino receives your account identifier, email address, and display name from the configured Supabase authentication service. Mino sends your todo text, completion state, date, and update time to that Supabase project only to synchronize your todos across your own devices. Mino does not sell this data or use it for advertising.

Third-party requests

When you type in the search field, Mino requests search suggestions from Google. When you submit a search, Chrome opens Google Search or the URL you entered. Shortcut icons may be requested from Google's favicon service using the shortcut URL. These requests are made only to provide the visible feature you use.

Data sharing and retention

Mino does not share personal data with third parties except the services needed for the features above: Google for sign-in, search suggestions, search, and favicons; and Supabase for optional authentication and todo synchronization. Local data can be removed by uninstalling the extension. Synced data is retained by the configured Supabase project until it is deleted there or through its retention settings.

Security

Network requests use HTTPS. Mino uses a public Supabase publishable key in the extension and relies on Supabase row-level security so authenticated users can access only their own synced todos.

Google API Services User Data Policy

Mino's use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Google account information is used only to authenticate the optional sync feature and is not used for advertising, profiling, or any unrelated purpose.

Your choices and contact

You can use Mino without signing in. You can remove local data by uninstalling the extension, and you can stop future synchronization by signing out. For privacy questions or data-deletion requests, open an issue at github.com/seyedhamzehsina/Mino/issues.
